# 02. 牌の定義

> 対応フェーズ: フェーズ1 ｜ 関連要件: REQUIREMENTS.md §3.2, §5.3
> 依存: #01

## 目的
麻雀牌のデータ表現と基本ユーティリティを定義する。以降の全ロジックの土台。

## 対象ファイル
- `src/lib/mahjong/tiles.ts`（純粋TS）

## スコープ / 仕様
- 標準34種136枚（萬子・筒子・索子 各1〜9、字牌 東南西北白發中）。
- 牌の内部表現を決める（例: `'m1'..'m9' | 'p1'..'p9' | 's1'..'s9' | 'z1'..'z7'`）。命名は §5.5 のSVGファイル名と一致させる（`z1`東 / `z2`南 / `z3`西 / `z4`北 / `z5`白 / `z6`發 / `z7`中）。
- ユーティリティ: 牌種判定（数牌/字牌/老頭牌/么九牌）、スーツ・数字の取得、全34種・全136枚の生成、ソート、表示名（日本語・カッコ補足付き、§3.7）。
- ドラ表示牌→ドラ牌の対応（表ドラのみ / §3.2）。
- 純粋関数のみ。React・通信に非依存。
