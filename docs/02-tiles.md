# 02. 牌の定義

> 対応フェーズ: フェーズ1 ｜ 関連要件: REQUIREMENTS.md §3.2, §5.3
> 依存: #01

## 目的
麻雀牌のデータ表現と基本ユーティリティを定義する。以降の全ロジックの土台。

## 対象ファイル
- `src/lib/mahjong/tiles.ts`（純粋TS）

## スコープ / 仕様
- 標準34種136枚（萬子・筒子・索子 各1〜9、字牌 東南西北白發中）。
- 牌の内部表現を決める（例: `'m1'..'m9' | 'p1'..'p9' | 's1'..'s9' | 'z1'..'z7'`）。命名は §5.5 のSVGファイル名と一致させる（`z1`東 / `z2`南 / `z3`西 / `z4`北 / `z5`白 / `z6`發 / `z7`中）。
- ユーティリティ: 牌種判定（数牌/字牌/老頭牌/么九牌）、スーツ・数字の取得、全34種・全136枚の生成、ソート、表示名（日本語・カッコ補足付き、§3.7）。
- ドラ表示牌→ドラ牌の対応（表ドラのみ / §3.2）。
- 純粋関数のみ。React・通信に非依存。

## 実装メモ
- `src/lib/mahjong/tiles.ts`。牌は SVGファイル名と一致する文字列リテラル union（`m1`..`z7`）。
- 表示名は**漢数字＋読み仮名**（例 `一萬（いちマン）`、字牌 `中（ちゅん）` 等）。
- シャンテン計算用に `tileToIndex`/`tileFromIndex`（0-33）も提供。並び順＝index順＝ソート順を単一の出所に。
- 暫定スモーク（`src/lib/__smoke__.*`）は削除。`tiles.test.ts` 23ケースで網羅（枚数/順序/述語/index往復/ソート/ドラ境界/表示名）。
- 副作用で `eslint.config.mjs` の ignores に `coverage/**` を追加（生成物の lint 除外）。
