# 03. 山牌・配牌

> 対応フェーズ: フェーズ1 ｜ 関連要件: REQUIREMENTS.md §3.1, §3.2
> 依存: #02

## 目的
山牌の生成・シャッフル・配牌・ツモ・ドラ表示を管理する。

## 対象ファイル
- `src/lib/mahjong/wall.ts`（純粋TS）

## スコープ / 仕様
- 136枚をシャッフルして山を作る。**乱数はシード可能**にする（テストの再現性確保 / CLAUDE.md テスト規律）。
- 配牌: 4人へ13枚ずつ配る（親は実質14枚目をツモる進行）。
- ツモ（山からの取得）と残り枚数の管理。
- 王牌・ドラ表示牌（表ドラのみ / §3.2）。嶺上牌はカンあり仕様（§3.1）に対応。
- 流局判定に使う「山が尽きた」状態の表現。
- 純粋関数 + 不変データ構造を基本とする。
