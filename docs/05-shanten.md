# 05. シャンテン数計算

> 対応フェーズ: フェーズ1 ｜ 関連要件: REQUIREMENTS.md §3.3, §5.3, §8（フェーズ1）
> 依存: #02, #04

## 目的
手牌のシャンテン数（アガリまでの距離）と待ち牌を計算する。お助けモード・CPU思考の中核。

## 対象ファイル
- `src/lib/mahjong/shanten.ts`（純粋TS）

## スコープ / 仕様
- 通常形・七対子・（必要なら国士は対象外 §3.2）のシャンテン数を計算し、最小値を返す。
- 副露を考慮（鳴き後の残り面子数で計算）。
- **待ち牌の列挙**（聴牌時に有効牌を返す）— お助けモードのハイライト（§3.3）で使用。
- 受け入れ枚数（有効牌の種類）の算出 — CPU中・強の手作り（#09 / §3.4）で使用。
- パフォーマンス: お助けモードで頻繁に呼ぶため十分高速に。純粋関数で副作用なし。
