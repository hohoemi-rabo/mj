# 10. SVG麻雀牌素材の生成

> 対応フェーズ: フェーズ1 ｜ 関連要件: REQUIREMENTS.md §5.5, §8（フェーズ1）
> 依存: #01（並行着手可）

## 目的
ライセンス問題を回避し、シニア向けに最適化した麻雀牌をSVGで自作する。

## 対象ファイル
- `public/tiles/*.svg`（34種＋裏面）

## スコープ / 仕様（§5.5 デザイン仕様）
| 項目 | 仕様 |
|------|------|
| 形式 | SVG |
| viewBox | `0 0 60 80`（縦長3:4） |
| 背景 | 白 or 淡いクリーム |
| 枠線 | 濃いグレー `#333` / 2px |
| 角丸 | 6px |
| コントラスト | シニア向けに高コントラスト |
| 数字・図柄 | 大きめ・視認性最優先 |

- 命名規則: 萬子 `m1`〜`m9` / 筒子 `p1`〜`p9` / 索子 `s1`〜`s9` / 字牌 `z1`東 `z2`南 `z3`西 `z4`北 `z5`白 `z6`發 `z7`中 / 裏面 `back`。
- **将来差し替え可能な設計**（不満があれば「麻雀豆腐」素材へ差し替え / §5.5）。参照を一箇所に集約する。
