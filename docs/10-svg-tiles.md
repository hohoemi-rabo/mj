| 項目 | 仕様 |
|------|------|
| 形式 | SVG |
| viewBox | `0 0 60 80`（縦長3:4） |
| 背景 | 白 or 淡いクリーム |
| 枠線 | 濃いグレー `#333` / 2px |
| 角丸 | 6px |

## 実装メモ
- **様式（ユーザー確定）: 数字つき伝統柄**。伝統図柄（萬=漢数字＋萬／筒=丸〈ドーナツ状〉／索=竹）に、**左上へスーツ色のアラビア数字バッジ**を添えて初心者の可読性を両立。字牌は大きな漢字。スーツ色＝萬赤`#c0202a`/筒青`#1565c0`/索緑`#2e7d32`、字牌は東南西北黒・白青・發緑・中赤。
- **生成スクリプト** `scripts/generate-tiles.mjs`（Node ESM・依存なし、`npm run gen:tiles`）で `public/tiles/*.svg` 35枚を一括出力。色・サイズ・配置はスクリプト先頭の定数/`LAYOUTS` を直せば一括調整可（伝統的なドット配置を count 別に定義）。仕様: viewBox `0 0 60 80`・背景`#FBF7EC`・枠`#333`2px・角丸6px・高コントラスト。
- **パス解決を集約**: `src/lib/tileAsset.ts`（`tileImagePath(tile)` / `TILE_BACK_PATH` / `TILE_BASE_PATH`）。UIは必ずこれ経由。将来 麻雀豆腐 等へは BASE_PATH かこの関数の差し替えのみ（牌名は `tiles.ts` の `Tile` と一致済み）。
- s1 は伝統の鳥ではなく竹1本に簡略化（数はバッジで明確）。CJK文字はOSフォント依存（font-family に BIZ UDPGothic 等のフォールバック）。図柄（丸/竹）はフォント非依存。
- `tileAsset.test.ts`: パス解決の網羅／**35ファイルの実在**（完了条件の自動検証）／各SVGが `viewBox="0 0 60 80"` を持つこと。
- 残: 実機/ブラウザでの横並び視認性チェック（不満なら色・サイズ調整、最終手段で素材差し替え）。

## 完了条件
