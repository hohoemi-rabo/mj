# 開発チケット一覧（インデックス）

## Todo の記法（全チケット共通）

各チケットは Todo を**チェックボックスで管理**する。

- 未完了: `- [ ]`
- 完了: `- [x]`（完了したら `- [ ]` を `- [x]` に書き換える）

チケット自体が完了したら、下表のステータス欄も `- [x]` にする。
